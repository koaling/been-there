# Decision log

When you accept the skill's offer to log a decision, it adds a file here:
`decisions/YYYY-MM-DD-<slug>.md`

```markdown
# <Decision>
- Date: YYYY-MM-DD
- Choice: …
- Confidence: x/10
- Key assumptions: …
- Kill criterion: …
- Review on: YYYY-MM-DD
- Outcome (fill in at review): …
```

Reviewing outcomes later is how you find out whether "8/10" from the skill really means 8/10.

# Privacy policy · Been There

_Last updated: 2026-11-25_

Been There is a Claude skill: a set of instructions and a library of public precedents (Markdown and YAML files) that Claude reads while answering you.

- **No data collection.** The plugin has no servers, no analytics, no telemetry and no MCP servers. The maintainer receives nothing you type.
- **What Claude processes.** Your prompts are handled by Claude under your own agreement with Anthropic (see [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy)). If web search is enabled in your Claude session, Claude may search the web for precedents using that tool.
- **Files on your computer.** If you ask for a decision log or a visual report, Claude writes it only where you choose, on your own machine or in your own Claude workspace. Nothing is sent to the maintainer.
- **Contact.** Questions: open an issue at https://github.com/koaling/been-there/issues.

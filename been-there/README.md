# Been There

The plugin folder of [Been There](https://github.com/koaling/been-there): a Claude skill that checks your plan against companies that already tried it (who failed, who survived) and returns a short verdict with a 48-hour test and a kill criterion.

- `SKILL.md`: the skill
- `precedents/`: the sourced precedent library (one YAML per company)
- `templates/report.html`: the optional visual report

Install, examples, evals and contributing guide: see the [main README](https://github.com/koaling/been-there#readme).
